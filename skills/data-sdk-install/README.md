# data-sdk-install

Install or upgrade the public reopt Data SDK suite in a consumer project. It provides a complete Next.js App Router path and routes React, vanilla browser, Node, and devtool work to the installed package READMEs.

## Use when

- adopting reopt Data tracking in an application
- upgrading the client/server package pair
- adding request-scoped server tracking, first-party ingest, consent, or SDK devtools
