# data-sdk-integration

Plan and implement a complete reopt Data event layer after the SDK transport is
installed: measurement design, typed contracts, browser and server events,
consent, catalogue-as-code, and end-to-end verification.

## Use when

- adding product analytics events to a consumer application
- turning user journeys into a durable event taxonomy and funnels
- migrating an existing analytics contract to Reopt Data without duplicate or
  divergent payloads
