# opt-ui-install

Install, upgrade, or add a page-template Block/Surface to `@reopt-ai/opt-ui` in a consumer project. Wires Tailwind CSS v4, `OptThemeProvider`, optional app-frame CSS, and the Block CLI.

## Use When

- a new consumer project needs Tailwind v4 + opt-ui theme set up
- upgrading opt-ui and need the impact scan plus relevant `block doctor` / `harness doctor` checks
- adding a page template via `npx @reopt-ai/opt-cli block add <slug>`
